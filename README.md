# トコリコ 公開ページ

「トコリコ」の公式ホームページと、利用規約・プライバシーポリシーなどの公開ページ(GitHub Pages)です。tocorico.jp につなぐ予定です(つなぐまでは https://pura-pixel.github.io/tocorico/)。

- ホームページ(トップ):index.html
- 予約の紹介ページ:booking.html(/booking)
- App Store の案内:app.html(/app。公開のときに App Store のトコリコのページへつなぎ直す)
- 利用規約:terms.html
- プライバシーポリシー:privacy.html
- お知らせの一覧(アプリが読む):news.json(書き方と足し方は [NEWS.md](NEWS.md))
- たよりの中身(アプリが読む):tayori.json(元のファイルはアプリのコードのフォルダの src/data/tayori.json。ここの写しは直接直さず、元のファイルを直して写す)

ホームページ(index.html・booking.html・booking-review.html・app.html・assets/・media/・og.png・robots.txt・sitemap.xml)の元は、アプリのコードのフォルダの docs/homepage/ です。ここは直接直さず、元を直して組み立ててから写します。
文書の元は別の場所で管理しています。このリポジトリは公開用の置き場です。フォント「Zen Maru Gothic」「Mochiy Pop One」は SIL Open Font License(fonts/OFL.txt・assets/fonts/OFL-*.txt)です。
